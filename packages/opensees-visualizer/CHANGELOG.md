# Changelog

## 1.0.0 - 2026-09-29

- Add typed capture of active 2D and 3D OpenSees domains.
- Render undeformed and deformed models with extensible element topologies.
- Add mode-shape and response-history animation.
- Add reactions, displacement colors and N, V2, V3, T, M2 and M3 diagrams.
- Add selection, labels, standard views, screenshots and headless 2D SVG export.
- Add a standalone Node launcher and a browser/Electron renderer entry point.
- Add full nodal-DOF inspection, element station forces and WebM animation export.
